# AI-Native Software Engineer Learning Path

A progressive, hands-on learning journey for experienced software engineers transitioning to **AI-Native / Agentic Software Engineering**.

---

## 🎯 Objective

Transform a traditional software engineer into an AI-Native / Agentic Software Engineer capable of designing, building, and deploying intelligent agent systems at scale.

---

## 🧠 Philosophy

This learning path is built on three core principles:

- **70% Practical / 30% Theory**: Learn by building real systems, not just reading papers
- **Learn by Building**: Each module culminates in concrete projects and exercises
- **Progressive Complexity**: Start with fundamentals, progressively build advanced multi-agent systems
- **Production-Ready Focus**: Understand patterns used in real-world AI systems

---

## 🚀 What You'll Learn

By completing this roadmap, you'll master:

- How Large Language Models work and their capabilities/limitations
- Prompt engineering and context engineering best practices
- Building tool-augmented systems (function calling, tools)
- Designing and implementing agentic systems
- Composing specialized skills and capabilities
- Multi-agent orchestration and subagents
- Model Context Protocol (MCP) integration
- Evaluating and testing agent systems
- Building an AI Software Factory

---

## 🛣️ Learning Logic & Prerequisites

The progression follows this path because:

```
AI Fundamentals
    ↓
LLM Fundamentals
    ↓
Prompt & Context Engineering (You need to understand prompts before tools)
    ↓
Tools / Function Calling (Tools are used by agents)
    ↓
Agents (Build on top of LLMs + tools)
    ↓
Skills (Specialized agent capabilities)
    ↓
Multi-Agent Systems (Compose multiple agents)
    ↓
MCP (Standard protocol for scale)
    ↓
Evals (Measure quality before production)
    ↓
AI Software Factory (Apply everything together)
```

## 🎯 Capstone Project: AI Software Factory

The final module brings everything together into a production-like system that:

1. Takes a software story/requirement as input
2. Generates specifications and design documents
3. Plans implementation across multiple specialized agents
4. Generates code, tests, and documentation
5. Evaluates quality and safety
6. Produces a pull request ready for human review

This architecture demonstrates mastery of:
- Multi-agent orchestration
- Specialized skills and tools
- Prompt engineering at scale
- Agent evaluation and testing
- Production-ready design patterns
