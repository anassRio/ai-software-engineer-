# 04 — Agents

## 🎯 Objective

Understand and build autonomous agent systems that can reason, plan, and act. By the end of this module, you should:

- Understand the agent loop (reasoning → action → observation → repeat)
- Know different agent architectures and patterns
- Build agents that can autonomously solve problems
- Handle agent failure modes and edge cases
- Evaluate agent performance and reliability

---

## 🧠 Concepts

- **The Agent Loop**: ReAct, Think-Act, Plan-Execute patterns
- **Reasoning**: How agents think through problems
- **Action Selection**: Choosing what to do next
- **Observation Integration**: Learning from environment feedback
- **Agent State Management**: Tracking context and history
- **Failure Modes**: When and why agents fail
- **Agent Patterns**: Different architectural approaches
