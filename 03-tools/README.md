# 03 — Tools / Function Calling

## 🎯 Objective

Understand how to augment LLMs with external tools and capabilities through function calling. By the end of this module, you should:

- Understand function calling and structured output from LLMs
- Design effective tool interfaces for LLM consumption
- Implement tool execution and error handling
- Chain multiple tools together
- Build reliable tool-augmented systems

---

## 🧠 Concepts

- **Function Calling**: How LLMs can call external functions/APIs
- **Tool Design**: Creating interfaces LLMs can reliably use
- **Structured Output**: JSON, function definitions, schemas
- **Tool Chaining**: Sequential and parallel tool execution
- **Error Handling**: What to do when tools fail or LLMs misuse them
- **Tool Context**: How to make tools discoverable to LLMs
- **Tool Selection**: How to help LLMs choose the right tool

- Build a simple tool and teach an LLM to use it

- Build a tool chaining system
