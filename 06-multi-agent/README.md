# 06 — Multi-Agent / Subagents

## 🎯 Objective

Understand and implement systems with multiple coordinated agents. By the end of this module, you should:

- Design multi-agent architectures and orchestration patterns
- Build agents that delegate to subagents
- Implement communication and coordination between agents
- Handle complex workflows with multiple specialized agents
- Evaluate multi-agent system performance

---

## 🧠 Concepts

- **Multi-Agent Orchestration**: Coordinating multiple agents
- **Agent Specialization**: Different agents for different tasks
- **Delegation Patterns**: How agents assign work to subagents
- **Inter-Agent Communication**: Passing information between agents
- **Hierarchical Agents**: Manager/worker agent patterns
- **Parallel Execution**: Running agents concurrently
- **Consensus & Voting**: Combining outputs from multiple agents
